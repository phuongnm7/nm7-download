# NM7 Download

Kho phát hành APK cố định cho NM7.

## Link cố định sau khi triển khai Vercel

- TV: `/NM7-TV.apk`
- Mobile: `/NM7-Mobile.apk`

Các file APK thực tế được lưu dưới `public/` với tên cố định. Khi có bản mới, chỉ thay nội dung file tương ứng và giữ nguyên tên để URL tải không đổi.

## Cập nhật

- TV: thay `public/NM7-TV.apk`
- Mobile: thay `public/NM7-Mobile.apk`

Vercel sẽ phục vụ trực tiếp hai file này từ cùng một project.
